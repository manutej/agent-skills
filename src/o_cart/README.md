# o-cart Python overlay

Tiny, original helpers that sit on top of the forked CARTO agent-skills catalog.

- `GeoLayer` — name a warehouse source for an Ormus pipeline
- `WorkflowSpec` — compose CARTO skills into an Ormus DAG
- `ormus_spatial_pipeline()` — default enrich / hotspot / route sequence

This is not a reimplementation of CARTO Workflows and does not include proprietary extension-package code.
